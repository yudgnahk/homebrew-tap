# yudgnahk/homebrew-tap

Homebrew casks for apps by [@yudgnahk](https://github.com/yudgnahk).

```bash
brew tap yudgnahk/tap
brew trust yudgnahk/tap      # Homebrew 7+ refuses casks from untrusted taps; skip on older Homebrew
brew install --cask pare
```

| Cask | App |
|---|---|
| `pare` | [Pare](https://github.com/yudgnahk/pare), safety-first disk cleanup for macOS 13+ (Apple silicon and Intel) |

Current builds are ad-hoc signed and not notarized: on first launch, open
System Settings > Privacy & Security and click "Open Anyway".
